# PrimeTrade Market Sentiment Analysis

## Overview

This project analyzes the relationship between Bitcoin Fear & Greed Index sentiment and Hyperliquid trader behavior. The objective is to identify how market sentiment influences trading decisions, profitability, win rates, and risk exposure.

## Dataset

The analysis uses:

* Bitcoin Fear & Greed Index data
* Historical Hyperliquid trader performance data

## Objectives

* Analyze trader behavior across different market sentiment conditions.
* Measure profitability and win rates under varying sentiment levels.
* Identify patterns between sentiment and trading performance.
* Generate actionable insights from the data.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Repository Structure

* `data/` – Source datasets
* `notebooks/` – Analysis notebook
* `charts/` – Generated visualizations
* `report/` – Final submission report

## Key Findings

* Market sentiment significantly influences trader behavior.
* Extreme Fear and Extreme Greed periods show distinct trading patterns.
* Profitability and risk exposure vary across sentiment categories.
* Data visualization reveals clear trends between sentiment and trader performance.

* Data analysis notebook
* Visual charts and graphs
